# Aloeworld LSF App - versão estática

Esta versão não usa React nem Vite. É um ficheiro HTML autónomo, pronto para publicar na Vercel.

## Vercel
- Framework Preset: Other
- Install Command: npm install
- Build Command: npm run build
- Output Directory: dist
- Root Directory: ./

Também pode publicar como site estático porque a app está toda em `index.html`.
